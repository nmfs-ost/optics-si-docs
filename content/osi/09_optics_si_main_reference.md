# Optics-SI-Main Reference Guide

Primary source repository: [nmfs-ost/Optics-SI-Main](https://github.com/nmfs-ost/Optics-SI-Main)

Use this page as the local entry point for linking SI-wide standards and implementation details back into this hub.

## What to pull from Optics-SI-Main
- Governance and role definitions
- Program standards and operating procedures
- Cloud and processing conventions
- Dataset and annotation policy updates
- Model intake and release expectations

## Suggested mapping into this hub
- Map cloud standards into [Cloud Storage](05_cloud_storage.md) and [Cloud Processing](06_cloud_processing_viame_web_app.md).
- Map model standards into [VIAME and Ultralytics Models](07_viame_ultralytics_models.md) and [Bring Your Own Trained Model](08_bring_your_own_model.md).
- Map program guidance into [Overview](01_overview.md) and [Implementation Roundtable](../05_module/01_qa_roundtable.md).

## Recommended curation workflow
1. Review upstream changes in Optics-SI-Main on a regular cadence.
2. Log relevant updates in implementation roundtable notes.
3. Propagate approved changes to local OSI pages.
4. Add or update references in [Resources](../01_resources.md).
